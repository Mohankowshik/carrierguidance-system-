Why We Need It

RandomForest is scale-invariant, but the scaler is retained so that: (a) feature distributions match training exactly, (b) if we later switch to SVM / KNN / LogReg no retrain is needed, (c) it keeps parity with the training pipeline in train_model.py.

🧪 How The 2 Files Are Loaded & Used (Code)

# app.py — lines 18-29 import pickle, os MODEL_PATH = "Models/model.pkl" SCALER_PATH = "Models/scaler.pkl" if os.path.exists(MODEL_PATH) and os.path.exists(SCALER_PATH): model = pickle.load(open(MODEL_PATH, 'rb')) # ← model.pkl deserialized here scaler = pickle.load(open(SCALER_PATH, 'rb')) # ← scaler.pkl deserialized here class_names = model.classes_
# Prediction step in app.py — get_career_recommendations() feature_array = np.array([[gender, part_time, absence, extra, self_study, math, hist, phys, chem, bio, eng, geo, total, avg]]) scaled_features = scaler.transform(feature_array) # ⬅ scaler.pkl used here probabilities = model.predict_proba(scaled_features) # ⬅ model.pkl used here top_3 = sorted(zip(class_names, probabilities[0]), reverse=True)[:3]

🔁 Training Workflow — How The .pkl Files Were Born

# train_model.py — end-to-end 1. Read student-scores.csv (2000 rows × 12 cols) 2. Engineer total_score & average_score (14 features ready) 3. Encode gender → F=1 / M=0 ; part_time & extracurricular → 0/1 4. Scale X = StandardScaler().fit_transform(X) → save scaler → scaler.pkl 5. Split 80% Train / 20% Test (1600 / 400, seed 42) 6. Train RandomForestClassifier(n_estimators=100, random_state=42) 7. Eval Accuracy = 47.00% on 17-class multi-class task 8. Save model → Models/model.pkl (21.9 MB)
🎙️ Interview Talking Points (for Sir)
  • My project uses two binary model files stored in the Models/ folder: model.pkl (the trained ML classifier) and scaler.pkl (standardization parameters).
  • Both files are produced by train_model.py and then loaded once at Flask startup in app.py lines 22–29.
  • Because .pkl files are serialized Python objects, they aren't human-readable text — which is why I built this Model Report page to document them visually.
  • The classifier is a Random Forest of 100 trees trained on 2,000 labelled students; it predicts across 17 career categories using 14 input features.
  • Live demo: go to /career, enter marks, submit — both files are invoked in real time to produce ranked careers and a probability pie chart.
